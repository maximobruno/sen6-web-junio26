# Skills de marca SEN6 para Claude

Ocho skills para que cualquier socio o colaborador cree piezas con la marca SEN6 usando Claude (Claude Code o Claude con skills activadas).

| Skill | Para qué |
|---|---|
| sen6-marca | El núcleo: colores, tipografías, logo, voz y checklist. Instalala siempre. |
| sen6-presentacion | Clases, pitch y decks en HTML 16:9 con el motor de SEN6. |
| sen6-web | Webs y landings autocontenidas. |
| sen6-reel | Reels y video vertical con motion en código. |
| sen6-miniatura | Miniaturas de YouTube simbólicas, con formas planas. |
| sen6-documento | Propuestas, media kit, reportes y PDF A4. |
| sen6-redes | Carruseles, historias, posts y portadas. |
| sen6-3d | 3D solo para pósters y piezas adicionales (láminas, fondos, merch) con Blender o three.js. |

## Cómo se instalan
**Claude Code:** descomprimí el zip y copiá cada carpeta a `~/.claude/skills/` (o pedile a Claude: "instalá las skills de esta carpeta en ~/.claude/skills").
**Claude (app / web):** Configuración → Capacidades → Skills → subir cada carpeta comprimida como .zip.

Después, pedí normal: "armame una presentación para sponsors con la marca SEN6", "hacé un carrusel sobre nichos", "revisá si esta miniatura respeta la marca".
